# Pull Request

## Context

- Current branch: !`git branch --show-current`
- Default base: !`git symbolic-ref refs/remotes/origin/HEAD --short 2>/dev/null || echo "origin/main"`
- Commits on branch: !`git log origin/HEAD..HEAD --oneline 2>/dev/null || git log --oneline -10`
- Changed files: !`git diff origin/HEAD..HEAD --stat 2>/dev/null || git diff --stat HEAD~5`

## Title and Description

Write the title and body with the `tidy-pr` skill (`~/.claude/skills/tidy-pr/SKILL.md`): written for a reviewer with no context from this session, no jargon, no padding.

## Rules

- **NEVER** mention code was generated by Claude
- Link related issues (Linear/GitHub) if applicable
- Use `$ARGUMENTS` as the base branch if provided; ask if unsure
- Never merge the PR; I merge via the GitHub UI

## Process

1. Ensure all changes are committed
2. Push with tracking if needed (`git push -u origin <branch>`)
3. Draft the title and body with `tidy-pr`, then create the PR with `gh pr create`
4. In a bork session (`BORK_ISSUE_ID` set), link it: `bork integration attach-pr <pr-number>`
